Claude Token Usage Tracker

Know exactly what your Claude API costs — right from your macOS menu bar.

What It Does

A native macOS menu bar app that connects to the Anthropic Admin API and shows your organization's Claude API usage and costs — broken down by month, model, workspace, and API key.

Features

  • Near real-time cost tracking via Intraday tab (~1h delay)
  • Monthly cost breakdown with full history
  • Per-model cost view — Claude Opus, Sonnet, Haiku
  • Per-API-key filtering — isolate costs by project or bot
  • Workspace overview — compare across environments
  • Live rate limits per model
  • Spend limit tracking with notifications
  • Multi-currency support (USD, EUR, GBP, and more)
  • CSV export for reporting
  • Built-in JSON API for integrations
  • Detached popover mode
  • Secure — API key in macOS Keychain, zero third-party dependencies

Requirements

macOS 14.0 (Sonoma) or later. Requires an Anthropic Admin API key.
